# @openmatrix/oms-ac-login

Embedded Account Connect Login package for this Next.js MVP.

## Public entry points

- `@openmatrix/oms-ac-login`
- `@openmatrix/oms-ac-login/next`
- `@openmatrix/oms-ac-login/react`

## Implemented in this MVP

- HMAC signed `openmatrix-session` cookie
- Local primary auth adapter
- JSON user store with `identities[]`
- Mock connect callbacks for Open Campus, GitHub, Google, Facebook and X
- App Router API handlers under `/api/ac/*`
- React provider, hooks, login page, connected accounts panel and credentials gallery
